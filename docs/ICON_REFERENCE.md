## Usage Examples

### Example 1: Restaurant Icon at Different Sizes

```json
{
  "icon-image": "restaurant-15",
  "icon-size": 1.0
}
```

### Example 2: Zoom-Based Icon Selection

```json
{
  "icon-image": [
    "match",
    ["zoom"],
    11, "restaurant-11",
    15, "restaurant-15",
    "restaurant-22"
  ]
}
```

### Example 3: Category-Based Icons

```json
{
  "icon-image": [
    "match",
    ["get", "class"],
    "restaurant", "restaurant-15",
    "cafe", "cafe-15",
    "bar", "bar-15",
    "hotel", "hotel-15",
    "shop", "shop-15",
    "attraction"
  ]
}
```

### Example 4: High-DPI Aware

MapLibre automatically selects @2x versions on Retina displays:

```json
{
  "icon-image": "restaurant-15"
  // Will use restaurant-15 on standard
  // Will use restaurant-15 from @2x sprite on Retina
}
```

## Icon Naming Pattern

All Maki icons follow this naming convention:

```
{icon-name}-{size}

Examples:
- restaurant-11 (small)
- restaurant-15 (medium)
- restaurant-22 (large)
```

### Available Sizes

- **11px** - For high zoom levels (17+)
- **15px** - For medium zoom levels (10-16)
- **22px** - For low zoom levels (0-9)

## Color Variations

While base Maki icons are monochrome, you can apply colors via style paint:

```json
{
  "paint": {
    "icon-color": [
      "match",
      ["get", "class"],
      "restaurant", "#d97200",   // Orange
      "hotel", "#5d60be",        // Blue
      "shop", "#76a723",         // Green
      "#626262"                  // Gray
    ]
  }
}
```

## Performance Notes

1. **Icon Loading**: All icons are in a single sprite sheet for efficient loading
2. **Caching**: Icons are cached by TileServer GL; configure cache times in config
3. **Rendering**: Icons render efficiently via the sprite sheet
4. **File Size**: ~80KB standard, ~320KB @2x (compressed)
5. **No Network Requests**: All icons loaded once, then rendered from sprite

## Finding Icons

### Method 1: Browse Online

Visit [Maki Editor](https://labs.mapbox.com/maki/) to browse all 600+ icons visually.

### Method 2: Check Sprite Metadata

```bash
curl http://localhost:8080/sprites/osm-liberty.json | jq 'keys[]'
```

This lists all available icon names.

### Method 3: Search

Look for icons by keywords:
- `restaurant` - All food-related icons
- `transport` - All transportation icons
- `building` - Infrastructure icons
- `nature` - Outdoor icons

## Custom Icon Colors

To color icons dynamically based on data:

```json
{
  "id": "poi-with-colors",
  "type": "symbol",
  "layout": {
    "icon-image": "restaurant-15",
    "icon-color": ["get", "color"]  // Uses color property from data
  }
}
```

## Troubleshooting

### Icon Not Displaying

1. Check icon name is correct
2. Verify sprite URL is configured
3. Ensure file is in sprite JSON metadata

```bash
# Check if icon exists
curl http://localhost:8080/sprites/osm-liberty.json | jq '.["restaurant-15"]'
```

### Wrong Icon Size

Icons are designed for specific zoom ranges. Use zoom-based sizing:

```json
{
  "icon-image": "restaurant-15",
  "icon-size": [
    "interpolate", ["linear"], ["zoom"],
    10, 0.6,   // Small at zoom 10
    15, 1.0,   // Standard at zoom 15
    18, 1.4    // Large at zoom 18
  ]
}
```
