QUICK START (5 MINUTES)
================================================================================

1. Verify prerequisites:
   bash scripts/verify-setup.sh

2. Download data:
   bash scripts/download-algeria-data.sh

3. Install TileServer:
   npm install -g @mapbox/tileserver-gl-cli

4. Start server:
   npm run tileserver

5. Open browser:
   http://localhost:8080

TECHNICAL SPECIFICATIONS
================================================================================

DATA COVERAGE
  Geographic Area: Algeria
  Bounds: 2.0°E - 9.0°E, 18.0°N - 37.0°N
  Data Source: OpenStreetMap via Geofabrik
  Zoom Levels: 0 - 14
  Features: Roads, buildings, water, landuse, POIs, boundaries

SYSTEM REQUIREMENTS
  Node.js: 14+ (recommended 16 or 18)
  RAM: 2GB minimum (8GB for processing)
  Disk: 50GB (for data processing)
  OS: Linux, macOS, Windows (with WSL2)

PERFORMANCE
  Tile serving: < 50ms per tile
  Concurrent clients: 1000+
  Memory base: ~500MB + cache
  Cache hit rate: >80%

FILE SIZES
  OSM Input: ~180MB
  MBTiles Output: 2-8GB
  Fonts: ~50MB
  Style: 382KB
  Total: ~10GB recommended storage

  Start server: < 10 seconds
